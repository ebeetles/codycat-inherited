# Handoff report: Cozy Cat Café

I read the spec.md file first, with all the acceptance criteria and such. I felt like it was pretty helpful, it had the full design, as well as different parts.

The spec was pretty clear, I know exactly what the author wanted, and the acceptance criteria were all checkable. The code was structured pretty well, with all the numbers that can be changed in config.js, there's clear objects, and the game state is also very clear. 

Something that cost me some time were the UI placeholders, as the real UI with the pixel art to be implemented had to refactor a lot of ui.js that was the main reason why original code got refactoreed. One thing I'd ask the author to do a little differently next time is maybe find a way to keep the art separate from the page layout. This way when we need to replace the placeholder emojis with the pixel art, we won't have to rewrite most of ui.js.
